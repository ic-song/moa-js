# 초기 버전 검증 기록

기준일: 2026-11-15. 결과는 현재 초기 구현 범위에 한정합니다. RealGrid 전체 기능·API 호환 또는 모든 운영 환경에서의 사용을 인증하는 기록이 아닙니다.

## 통과한 검사

| 검사 | 결과 |
| --- | --- |
| Node 모델 테스트 | 12개 통과: 다중 셀 작업의 원자성, 읽기 전용, Delete, Undo/Redo, 새 편집 후 Redo 폐기, 검증 실패, 데이터 교체, 이력 제한, TSV 특수문자 |
| Chromium 브라우저 검사 | 14개 흐름 통과: 실제 키·마우스 입력, 클립보드 쓰기·읽기, 드래그, Shift 선택, Delete·붙여넣기·Undo/Redo, 검증 오류, 정렬·검색 후 원본 행 반영, CSV 다운로드 |
| 폐쇄망 실행 | 브라우저 offline 모드에서 file:// 예제 로드·편집·Undo 성공, HTTP 요청 0건, JS 예외 0건 |
| 배포 형식 | 일반 script 예제, ESM import, CommonJS require 확인 |
| 오프라인 빌드 | Node 내장 파일 기능만으로 브라우저 JS·ESM·CommonJS·CSS 생성 |
| 패키지 점검 | npm pack dry-run에서 배포 파일·README·LICENSE만 포함, 런타임 의존성 없음 |
| 기능 문서 | 후보 167개: M0 33 / M1 44 / M2 50 / M3 34 / 독립 확장 6. ID·분류·출처와 생성 문서 일치 검사 |
| 반응형 자동 캡처 | 7개 기본 화면 크기와 640px 경계, 기본·선택·빈 결과·편집·오류·삭제·읽기 전용 상태 등 34개 캡처 |
| 반응형 너비 스캔 | 320~2560px 범위의 38개 너비에서 문서 가로 넘침 0건, 브라우저 오류 0건 |

모델 검사는 `npm test`, 빌드는 `npm run build`, 카탈로그 검사는 `npm run catalog -- --check`로 재실행할 수 있습니다. 모델 검사·빌드에는 npm install이 필요 없습니다.

브라우저 검증에는 개발 도구인 Playwright 1.66.0-alpha-1794252756000 / Chromium 158.0.8127.18을 사용했습니다. 개발 환경에서 해당 Playwright 패키지와 Chromium을 준비한 후 `node scripts/serve.mjs`를 실행하고, 다른 터미널에서 `node scripts/browser-check.mjs`를 실행합니다. Playwright는 배포 패키지나 실행 의존성에 포함하지 않습니다. 브라우저 설치는 인터넷이 필요할 수 있으며 사용자의 폐쇄망 런타임 실행과 구분합니다.

## 시각·접근성 검토 상태: DEGRADED

데스크톱 오프라인 전체 화면, 모바일 기본 화면, 모바일 선택 상태, 데스크톱·모바일 검증 오류의 대표 이미지를 확인했습니다. 전체 34개 캡처와 원본 슬라이스의 개별 수동 검토는 완료하지 않았습니다. 따라서 시각 품질 게이트 전체 통과로 보고하지 않습니다. 소스 기계 검사에서 차단 결함은 없었고 캡처·너비 스캔도 성공했으나, 전체 이미지 수동 검토와 접근성 검증이 남아 DEGRADED 상태입니다.

작은 화면의 표는 내부 가로 스크롤을 의도적으로 사용합니다. 스캐너가 감지한 화면 밖 헤더 버튼은 이 스크롤 영역 안에 있으며 문서 전체 넘침과 구분했습니다. 현재 드래그 자동 스크롤은 구현하지 않았습니다.

검증 도구의 Windows 링크 경로 진입점과 최신 Chromium의 RGB PNG를 처리하기 위해, 무시되는 output 폴더에 복사한 캡처 도구에만 진입점·RGBA 정규화를 적용했습니다. 설치된 스킬이나 제품 소스는 이 우회 처리로 수정하지 않았습니다.

## 남은 수용시험·기능

- 실제 Microsoft Excel 애플리케이션에 붙여넣고 다시 가져오는 왕복 시험. 현재는 브라우저 시스템 클립보드와 TSV 형식을 확인했습니다.
- 실제 Windows 한글 IME 조합 입력, macOS 단축키, Firefox·Safari 등 다른 엔진, 모바일 실기기.
- NVDA·VoiceOver 등 스크린리더, 자동 접근성 감사와 전체 대비 검사.
- 대용량 성능·메모리·가상 스크롤. 현재 DOM 렌더는 전체 검색 결과를 생성하며 대용량 성능을 약속하지 않습니다.
- XLSX·서버 저장·행 추가/삭제·조건 필터·그룹·트리·완전한 RealGrid API 이행. 카탈로그에서 계획 또는 일부 구현으로 표시합니다.

로컬 원본 검증 자료는 `.codex/design/reviews/responsive/`와 `output/playwright/`에 보관하며 Git에 올리지 않습니다. 공개 저장소에는 이 요약과 재현 스크립트를 포함합니다.
