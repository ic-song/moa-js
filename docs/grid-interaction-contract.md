# 셀 조작 계약

사용자 지정 필수 요구사항을 첫 버전의 기준으로 고정합니다. 아래 단축키는 그리드 셀에 포커스가 있고 입력창 편집 중이 아닐 때 적용합니다.

| ID | 입력 | 결과 | 확인 기준 |
| --- | --- | --- | --- |
| UX-01 | 마우스 드래그 | 시작 셀과 끝 셀 사이 직사각형 선택 | 가로·세로·역방향 선택, 범위 강조 |
| UX-02 | Shift+방향키 | 최초 기준점 유지, 현재 셀 이동 | 선택 확대와 반대 방향 축소 |
| UX-03 | Ctrl+C | 선택 범위를 text/plain TSV로 복사 | 행은 CRLF, 열은 탭; 셀 내부 구분문자는 따옴표 처리 |
| UX-04 | Ctrl+V | 왼쪽 위부터 여러 셀 붙여넣기 | 2행×2열 한 번 적용, 숫자 변환, 읽기 전용 보호 |
| UX-05 | Delete | 선택 셀 값 일괄 지우기 | 행을 삭제하지 않으며 숫자는 null, 문자열은 빈 값 |
| UX-06 | Ctrl+Z | 가장 최근 데이터 작업 전체 취소 | 붙여넣기 또는 Delete 여러 셀이 한 번에 원복 |
| UX-07 | Ctrl+Y | 취소된 작업 전체 재실행 | Ctrl+Z→Ctrl+Y 후 모든 값 복원 |
| UX-08 | 새 편집 후 Ctrl+Y | 이전 재실행 이력 폐기 | 취소했던 과거 작업이 다시 적용되지 않음 |

macOS에서는 ⌘를 사용하고 다시 실행에 ⌘+Shift+Z도 지원합니다. 브라우저 입력창에서 문자를 편집 중일 때는 기본 텍스트 편집 동작을 유지합니다.

## 원자성과 보호 규칙

1. 변경 후보 전체를 수집합니다. 검색·정렬 후 표시 좌표를 원본 행 인덱스로 변환합니다.
2. 읽기 전용 셀은 그대로 두고 편집 가능한 셀만 검증합니다. 전체 읽기 전용 그리드는 변경하지 않습니다.
3. 잘못된 값 또는 required 오류가 있으면 **변경 전 상태를 그대로 유지**하고 오류를 안내합니다. 변경 이력도 추가하지 않습니다.
4. 통과한 변경을 한 번에 반영하고 Undo 이력 한 건을 기록합니다. 읽기 전용 셀과 동일한 값은 이력에 기록하지 않습니다.
5. Undo/Redo에서도 원본 행 인덱스를 사용해 정렬·검색과 데이터가 섞이지 않도록 합니다. `setData`는 새 데이터 기준으로 이력을 제거합니다.

예: B2:C4에 6개 값을 붙여넣고 Delete를 누르면 이력은 `붙여넣기`, `지우기` 두 건입니다. Ctrl+Z는 6개 값을 되살리고, 한 번 더 누르면 붙여넣기 전 값으로 복원합니다. Ctrl+Y는 같은 순서로 다시 적용합니다.

## 첫 버전의 범위

- 단일 직사각형만 지원합니다. 여러 비연속 영역·병합 셀·숨김 컬럼은 후속 기능입니다.
- 붙여넣기는 선택 크기를 반복 채우지 않고 선택 왼쪽 위부터 원본 TSV 크기대로 적용합니다.
- 그리드 끝을 넘는 데이터는 잘라서 반영하지 않고 전체 거부합니다. 행 자동 추가는 후속 기능입니다.
- 드래그 중 화면 밖으로 자동 스크롤하는 기능은 아직 없습니다. 현재 보이는 셀 사이에서 선택하거나 Shift+방향키를 사용합니다.
- CSV 파일 교환과 Excel 클립보드 교환을 지원합니다. XLSX 파일 입출력은 아직 구현되지 않았습니다.
- 실제 Microsoft Excel 애플리케이션과의 왕복, 한글 IME와 macOS 실기기 단축키는 별도 수용시험이 필요합니다.
