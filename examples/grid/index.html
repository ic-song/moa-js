품목코드는 읽기 전용입니다. 수량·단가에는 숫자만 입력할 수 있습니다. 붙여넣기는 선택 영역의 왼쪽 위부터 적용되며, 범위를 넘거나 유효하지 않은 값이 있으면 전체 작업을 취소합니다.

macOS에서는 Ctrl 대신 ⌘를 사용합니다. 셀 안에서 문자를 편집하는 동안에는 기본 텍스트 복사·붙여넣기와 실행 취소가 동작합니다. 변경은 메모리에만 유지되며 새로고침하면 초기화됩니다.

Moa JS는 독립 구현하는 JavaScript 도구 모음입니다. RealGrid의 구현 코드와 리소스를 포함하지 않습니다. 초기 버전으로 가상 스크롤·XLSX·완전한 API 호환은 제공하지 않습니다.
